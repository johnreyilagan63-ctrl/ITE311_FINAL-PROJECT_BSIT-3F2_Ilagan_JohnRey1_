# WAYTO Project Overview

## Project Purpose
WAYTO is a web-based information and accommodation management system for Lorenzo's Farm and Resort.

## Main Goal
The system aims to make resort information accessible and support the management of resort website content.

## Current Features
- Public resort homepage
- Editable homepage title and description through Filament
- Homepage banner image upload

## Technologies
- Laravel
- PHP
- Filament
- Git and GitHub

## Future Development
Accommodation management and additional resort features will be developed in later stages.
